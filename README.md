# Thrifted

Marketplace full-stack për shitjen/blerjen e veshjeve të reja dhe të përdorura (React + TypeScript frontend, FastAPI + PostgreSQL backend).

## Struktura

```
Thrifted/
├── backend/    → FastAPI, SQLAlchemy, Alembic
├── frontend/   → React, TypeScript, Tailwind, Vite
└── docs/       → Dokumentacioni i projektit dhe i fazave — shiko docs/README.md
```

## Dokumentacioni

Gjithë dokumentacioni (plani fillestar, roadmap, user stories, ERD, API contract, dhe progresi për-fazë) ndodhet te [`docs/`](docs/README.md).

Fillo nga [`docs/README.md`](docs/README.md) për indeksin e plotë.
